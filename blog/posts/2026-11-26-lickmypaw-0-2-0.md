LickMyPaw is a free, open source Mac cleaner. It maps your disk, clears caches and junk, uninstalls apps together with their leftovers, finds large and duplicate files, and checks your system for problems. It is MIT licensed, needs no account and sends no telemetry. This post covers what changed in 0.2.0.

## The short version

- A menu bar item with disk, memory, CPU and the Trash, one click away.
- Five new tools: Maintenance, a Privacy cleaner, a Shredder, an app Updater and more Cleanup categories.
- LickMyPaw can check for its own updates and install them, with the checksum verified.
- A hang at launch is fixed. More on that at the end.

## It lives in your menu bar now

![The LickMyPaw menu bar popover](assets/screenshots/14-menubar.png)

A paw icon in the menu bar opens a small popover with free disk space, memory pressure, CPU load and the size of your Trash. From there you can empty the Trash (it asks first), run Smart Care, or open the app. Closing the main window keeps LickMyPaw in the menu bar. You can turn the menu bar item off in Settings.

A cleaner that slows your Mac down would be a bad joke, so the menu bar item is built to cost almost nothing:

- The icon is static. Nothing is sampled while the popover is closed.
- While it is open, one sample every two seconds takes a few microseconds.
- In the background there is a single free-space check every five minutes. No scans, no directory walks, nothing else.

Launch at login is available and **off by default**. Notifications (disk almost full, Trash getting big) are also **off by default**, send at most one message a day, and the thresholds are yours to set.

## Maintenance

![Maintenance](assets/screenshots/10-maintenance.png)

The housekeeping macOS hides in Terminal, with a button each: flush the DNS cache, reindex Spotlight, rebuild the Launch Services database, clear font caches, verify the startup disk, and list or thin local Time Machine snapshots.

Every task shows the exact command it is about to run before it runs. The ones that need admin rights use the normal macOS password prompt. LickMyPaw never keeps your password.

## Privacy cleaner

![Privacy cleaner](assets/screenshots/11-privacy.png)

Caches, history, cookies and download lists for Safari, Chrome, Edge, Brave, Arc and Firefox, plus recent items, the Quick Look cache, quarantine events and, if you opt in, shell history. Browsers have to be quit first, and LickMyPaw can ask them to quit politely. Cookies start unchecked, because clearing them logs you out of things.

Everything goes to the Trash, so you can undo it. Safari needs Full Disk Access, and the app walks you through granting it.

## Shredder

![Shredder](assets/screenshots/12-shredder.png)

For the rare file that should really be gone: it overwrites the file with a random pass and a zero pass, then deletes it. This one **cannot be undone**, and the app asks you to confirm.

One honest caveat: on SSDs and APFS, overwriting a file does not guarantee the old blocks are the ones that get overwritten. For anything truly sensitive, full-disk encryption is the real protection. The Shredder says this in the app too.

## Updates for your other apps

![Updates tab in Applications](assets/screenshots/13-updates.png)

The Applications section has a new Updates tab. It finds which of your apps have an update waiting if they use Sparkle, the Mac App Store or a Homebrew cask. It talks to the network only when you press the button, and each app gets an action that fits how it updates: open its own updater, open the App Store, or run the `brew upgrade --cask` command after you confirm it.

## More things to clean

Cleanup learned a few more places where gigabytes hide: Mail downloads, iOS device backups, Simulator devices, and Xcode DeviceSupport and Archives. iOS backups and Archives start **unchecked**, because deleting them is rarely what you meant by "clean up".

## LickMyPaw updates itself

Once a day, LickMyPaw asks GitHub whether a newer release exists (you can turn this off, or check by hand with a button or `lickmypaw update --check`). If there is one, a banner tells you what is new. When you choose to install it, the app downloads the zip, checks its SHA-256 against the checksums published in the release, checks that it is really LickMyPaw, swaps itself and relaunches.

That check is one of only three things in the app that touch the network:

1. The GitHub release check, which you can switch off.
2. The ClamAV signature download, only if you install ClamAV from the app.
3. App update checks that you start yourself in Applications.

No identifiers are sent.

## What went wrong, and what we fixed

The first public build, 0.1.0, crashed on launch for anyone who downloaded it. The app looked for its resources in a folder that only exists on the machine that built it, so it worked for the developer and for nobody else. 0.1.1 fixed that, and the CI now unpacks the packaged app, hides the build folder and checks that it starts, so this cannot ship again.

While testing 0.2.0 the app hung at launch with 100% CPU and no menu bar icon. The cause was a feedback loop: SwiftUI writes the menu bar visibility back on every update, and wiring that straight to a stored setting turned each write into another update, forever. A second bug flipped the Dock and menu bar mode back and forth at launch, which also sent the window behind other windows. Both are fixed in 0.2.0, along with an update banner whose close button did not close it.

One security detail: `/etc` and `/var/db` are now refused by LickMyPaw's safety check. `/etc/hosts` slipped through it once symlinks were resolved. Every delete in the app goes through that single check.

## Honest limits

- Builds are **not signed and not notarized** yet. They are ad-hoc signed, which Apple Silicon needs to run them. macOS will warn you the first time. Right-click the app and choose Open, or remove the quarantine flag. Signing and notarization are planned for 1.0.0.
- Apple Silicon only, macOS 13 or later.
- There is no real-time malware monitor. The ClamAV scan is for checking files you downloaded, not a replacement for a full antivirus.
- A few flows have had less real-world testing than the rest: the admin password prompt in Maintenance, quitting a browser from the Privacy cleaner, and the self-update swap. If one of them misbehaves, please open an issue.
